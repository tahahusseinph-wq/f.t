# منظومة مجموعة فاروق الطعمة التجارية

منظومة متكاملة لإدارة المستودع والمبيعات، من تطبيقين:

| التطبيق | التقنية | الوصف |
|---|---|---|
| **تطبيق الأدمن** (`desktop/`) | Python + PySide6 + SQLite | جرد المستودع، البيع، الفواتير، التقارير، الإعدادات. ويشغّل سيرفراً محلياً للموبايل. |
| **تطبيق الموبايل** (`mobile/`) | Flutter (Android) | البحث بالكود ومسح الباركود، البيع، الجرد، لوحة تحكم للأدمن. يعمل على نفس الراوتر. |

## أهم الميزات

- **أول تشغيل**: معالج إعداد لإنشاء حساب الأدمن، بيانات المنشأة، العملات، ومفتاح استرجاع لمرة واحدة.
- **البضاعة**: أقسام متعددة المستويات، متغيرات (لون/مقاس)، صور، باركود وملصقات، **خانات مخصصة** تضيفها بنفسك وتحدد ظهور كل منها للمستخدمين.
- **توليد الكود** تلقائياً من القسم والماركة والاسم (مثل `ELC-SAMS-A54-0001`)، أو باقتراح من الذكاء الاصطناعي.
- **Gemini**: جلب تفاصيل ومواصفات المنتج، التعرّف على المنتج من صورة، قراءة فاتورة المورد من صورة، و«اسأل بياناتك» بالعربي.
- **التسعير**: نسبة ربح للمنتج أو القسم، شرائح جملة/مفرّق، عروض وخصومات مؤقتة، تحديث أسعار جماعي، سجل الأسعار، دولار/ليرة سورية.
- **المخزون**: حد تنبيه لكل منتج، تنبيهات النقص، تواريخ صلاحية بنظام FEFO، سجل الحركات، جرد فعلي (حتى من الموبايل)، تعدد المستودعات، اقتراحات الطلب.
- **المبيعات**: نقطة بيع مع قارئ الباركود، نقدي/آجل/جزئي، فاتورة PDF بالشعار (A4 أو إيصال 80mm)، مشاركة عبر واتساب، مرتجعات، عروض أسعار.
- **المالية**: الزبائن والديون وكشف الحساب، المصاريف، الورديات ومطابقة الصندوق، عمولات البائعين.
- **التقارير**: لوحة تحكم برسوم بيانية، نسبة مبيع كل منتج، الأقسام، أوقات الذروة، البضاعة الراكدة، تصدير Excel وPDF.
- **جرد Excel**: مجلد «جرد_التاريخ» فيه ملف منسق بورقة ملخص وورقة لكل قسم، واستيراد من Excel مع ربط الأعمدة.
- **الأمان**: كلمات سر Argon2، قفل بعد محاولات خاطئة، قفل الشاشة عند الخمول، صلاحيات لكل دور ولكل مستخدم، سجل نشاطات، إخفاء الحقول على مستوى السيرفر.
- **الاستمرارية**: نسخ احتياطي يومي مشفّر اختيارياً ونسخة سحابية عبر مجلد Google Drive، موبايل يعمل بدون اتصال ويزامن لاحقاً، بوت تيليغرام للتنبيهات والتقرير اليومي.

## البدء السريع

**تطبيق الأدمن (ويندوز):** ثبّت Python 3.12 ثم شغّل `desktop\run_windows.bat`، أو نزّل النسخة الجاهزة من GitHub Actions/Releases.

**تطبيق الموبايل:** ثبّت ملف APK، ثم امسح رمز QR الذي يظهر في تطبيق الأدمن (أعلى الشاشة ← حالة السيرفر).
