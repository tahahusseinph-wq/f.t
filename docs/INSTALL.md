# دليل التنصيب والاستخدام

## 1) تنصيب تطبيق الأدمن على الكمبيوتر

**الطريقة الأسهل (نسخة جاهزة):** من صفحة المستودع على GitHub ← Actions ← آخر تشغيل ناجح لـ «Build» ← نزّل `FaroukToumma-windows`، فك الضغط وشغّل `FaroukToumma.exe`.

**من الكود:**
1. ثبّت Python 3.12 من python.org (فعّل خيار *Add to PATH*).
2. افتح مجلد `desktop` وشغّل `run_windows.bat` (يجهّز كل شيء في أول مرة).

> البيانات تُحفظ في `%APPDATA%\FaroukToumma` (قاعدة البيانات، الصور، النسخ الاحتياطية، الفواتير).

### أول تشغيل
1. أنشئ اسم مستخدم وكلمة سر للأدمن.
2. أدخل بيانات المنشأة والعملة الأساسية والعملة الثانية وسعر الصرف.
3. (اختياري) أدخل مفتاح Gemini من [aistudio.google.com](https://aistudio.google.com).
4. **احفظ مفتاح الاسترجاع** — هو الطريقة الوحيدة لاستعادة الحساب إذا نسيت كلمة السر.

## 2) تنصيب تطبيق الموبايل
1. نزّل `FaroukToumma-android` (ملف APK) من GitHub Actions وثبّته (اسمح بالتثبيت من مصادر غير معروفة).
2. وصّل الموبايل على **نفس الواي فاي** الموصول عليه الكمبيوتر.
3. في تطبيق الأدمن اضغط على «السيرفر يعمل» أعلى الشاشة لعرض رمز QR.
4. في الموبايل اختر «مسح رمز QR»، ثم سجّل الدخول بنفس اسم المستخدم وكلمة السر.

**إذا لم يتصل:** اسمح للبرنامج في جدار حماية ويندوز (Private networks)، أو أدخل العنوان يدوياً مثل `192.168.1.10:8765`.

## 3) الاستخدام اليومي

| المهمة | أين |
|---|---|
| إضافة منتج | المنتجات ← منتج جديد (Ctrl+N). اترك الكود فارغاً ليُولّد تلقائياً. |
| خانة جديدة (مثل: بلد المنشأ) | الأقسام والخانات ← الخانات المخصصة، أو من داخل نافذة المنتج. |
| ماذا يرى المستخدم في الموبايل | الأقسام والخانات ← ما يراه المستخدمون. |
| جلب تفاصيل المنتج | نافذة المنتج ← التفاصيل والمواصفات ← «جلب التفاصيل بالذكاء الاصطناعي». |
| حد التنبيه | نافذة المنتج ← التسعير والمخزون ← حد التنبيه (الافتراضي من الإعدادات). |
| البيع | نقطة البيع (F2)، امسح الباركود، F9 لإتمام البيع، ثم طباعة/PDF/واتساب. |
| تصدير الجرد | المنتجات ← المزيد ← تصدير جرد البضاعة (مجلد Excel). |
| إضافة مستخدمين | المستخدمون ← مستخدم جديد، واختر الدور «مستخدم (بحث فقط)». |
| سعر الصرف | المالية ← العملات وأسعار الصرف. |
| الجرد الفعلي | المخزون ← جرد جديد، ثم المسح من الكمبيوتر أو الموبايل، ثم «تطبيق الجرد». |

### اختصارات لوحة المفاتيح
`Ctrl+K` بحث شامل • `F2` نقطة البيع • `F9` إتمام البيع • `Ctrl+N` منتج جديد • `Ctrl+L` قفل الشاشة.

## 4) النسخ الاحتياطي
- نسخة تلقائية يومية في `%APPDATA%\FaroukToumma\backups` (آخر 14 نسخة افتراضياً).
- للنسخ السحابي: ثبّت Google Drive للكمبيوتر، واختر مجلده من الإعدادات ← النسخ الاحتياطي.
- الاسترجاع: الإعدادات ← النسخ الاحتياطي ← استرجاع نسخة.

## 5) بوت تيليغرام
1. افتح @BotFather في تيليغرام ← `/newbot` وانسخ الرمز.
2. أرسل `/start` للبوت الجديد.
3. الإعدادات ← بوت تيليغرام: الصق الرمز، اضغط «اكتشاف تلقائي»، ثم فعّل وحفظ.
